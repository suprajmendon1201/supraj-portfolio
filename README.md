# Supraj Mendon — Personal Portfolio

A responsive React + Vite portfolio based on Supraj Mendon's supplied resume.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Push this folder to GitHub, then import the repository in Vercel. Choose **Vite**, build command `npm run build`, output directory `dist`.

## Notes

- The original resume is included in `public/Supraj-Mendon-Resume.pdf`.
- Review contact details before publishing publicly.
- No photograph or unverified work experience has been invented.
